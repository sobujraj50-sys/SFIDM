# SFIDM - Version 1 (Android Download Manager)

## Features Included in Version 1
- **Multi-Thread HTTP Downloader** (4x / 8x / 16x concurrent parts using HTTP Range headers)
- **Pause, Resume & Auto-Export** to your phone's `Downloads/SFIDM` folder
- **Foreground Service** with live progress & speed notification
- **Bilingual UI (বাংলা & English)** with instant 1-tap switcher
- **6 Dark Themes** built-in (Midnight Cyber, Obsidian Gold, Crimson Stealth, Emerald Terminal, Vapor Violet, AMOLED Mono)
- **Smart Clipboard Detection & Android Share Menu** integration

## How to Build APK on GitHub (No Coding Needed)
1. Unzip this folder on your phone or PC.
2. Create a new **Private** repository on GitHub (e.g. `SFIDM`).
3. Click **Add file → Upload files** and upload ALL files and folders inside this unzipped folder (make sure the `.github` folder is included!).
4. Click **Commit changes**.
5. Open the **Actions** tab at the top of your repository and wait 3–5 minutes for the green checkmark (✅).
6. Click the completed workflow run → scroll to **Artifacts** → download **SFIDM-v1-APK**, unzip it, and install `app-debug.apk` on your Android phone.
